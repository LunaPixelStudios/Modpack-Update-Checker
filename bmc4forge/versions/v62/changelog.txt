# [Ocean Update]

This update adds Hybrid Aquatic, an ocean overhaul mod with all kinds of aquatic life, alongside Hybrid Birds and Hybrid Delights, a culinary addon adding many new seafood dishes! To make seafaring more enjoyable, we've also added Shippy Ships, a new ship mod where you can build large ships and set sail across the ocean!

## Mod Changes

 - 🟢 Added [Hybrid Aquatic](https://www.curseforge.com/minecraft/mc-mods/hybrid-aquatic) (by HybridLabs)
 - 🟢 Added [Hybrid Birds](https://www.curseforge.com/minecraft/mc-mods/hybrid-birds) (by HybridLabs)
 - 🟢 Added [Hybrid Delights](https://www.curseforge.com/minecraft/mc-mods/hybrid-delights) (by HybridLabs)
 - 🟢 Added [Hybrid API [HAPI]](https://www.curseforge.com/minecraft/mc-mods/hybrid-api) (by HybridLabs)
 - 🟢 Added [Shippy Ships](https://www.curseforge.com/minecraft/mc-mods/shippy-ships) (by Caesius_Leo)
