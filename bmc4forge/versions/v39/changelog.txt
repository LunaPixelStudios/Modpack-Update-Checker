**[Minor Update]**
This update fixes the issue with hostile mobs not spawning naturally. This was due to the Spawners+ mod causing all mob spawners in the world to keep spawning mobs, even if players were not nearby, which made worlds reach the hostile mob limit. If this update does not fix the issue for you, you can try running the `/kill @e[type=minecraft:skeleton,type=minecraft:zombie,type=minecraft:spider]` command ingame to kill all mobs commonly found in spawners.
