# [Content Update]

This update finally removes the Backpacked mod in favor of Inmis. If you are updating from an older version please update to v56 first, as this will automatically convert your backpack and the items inside.

## Mod Changes

 - 🟢 Added [Soulful Nether](https://www.curseforge.com/minecraft/mc-mods/soulful-nether) (by CeasingBonsai)
 - 🟢 Added [The Brazilian Localization Project](https://www.curseforge.com/minecraft/texture-packs/brazilian-project) (by L200)
 - 🔴 Removed [Backpacked](https://www.curseforge.com/minecraft/mc-mods/backpacked) (Replaced)
 - 🔵 Updated 50 mods

### Config Changes

 - The Leaderboard button is no longer visible in singleplayer worlds - use the Statistics button instead

### Updates

 - Added all content from the Chaos Cubed update, including the Sulfur Caves biome and Sulfur Cubes ([Vanilla Backport](https://www.curseforge.com/minecraft/mc-mods/vanillabackport))
 - Many shader improvements, such as more performant light shafts, improved rain & snow, improved reflections, and overall improved performance ([Complementary Shaders - Reimagined](https://www.curseforge.com/minecraft/shaders/complementary-reimagined))
 - Added support for 50 more mods ([Modded Omelet](https://www.curseforge.com/minecraft/texture-packs/modded-omelet))

 - Added Onion Soup, Gleaming Salad, Rope Fence, and a new wooden variant for the Basket ([Farmer's Delight](https://www.curseforge.com/minecraft/mc-mods/farmers-delight))
 - Added new loot tables to the End ([MES - Moog's End Structures](https://www.curseforge.com/minecraft/mc-mods/moogs-end-structures))
 - Entities now create a splash when exiting water ([Wakes Reforged](https://www.curseforge.com/minecraft/mc-mods/wakes-reforged))
 - Improved villager name display ([Villager Names](https://www.curseforge.com/minecraft/mc-mods/villager-names))

 - Improved performance of wake rendering by 50% ([Wakes Reforged](https://www.curseforge.com/minecraft/mc-mods/wakes-reforged))
 - Improved game performance and reduced mouse latency ([Ixeris](https://www.curseforge.com/minecraft/mc-mods/ixeris))
