**[Stability Update]**
In this update, we have updated the Simple Storage Network mod to the latest version. This version of the mod has a bug that prevents hoppers from working with storage networks in some cases, but also fixes several crashes and other small bugs. After careful consideration, we decided that the hopper bug is less urgent than the game crashing issues. If you would like to continue using hoppers in your storage network, you are free to downgrade the Simple Storage Network mod to version 1.11.3
