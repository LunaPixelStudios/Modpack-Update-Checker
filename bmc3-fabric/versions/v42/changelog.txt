Mod Changes
 - Added [Nether Trials & Chambers](https://www.curseforge.com/minecraft/mc-mods/hellish-trials) (by Aureljz)
 - Added [Certain Questing Additions](https://www.curseforge.com/minecraft/mc-mods/certain-questing-additions) (by HollowHorizon)
 - Added [Concurrent Chunk Management Engine](https://www.curseforge.com/minecraft/mc-mods/c2me) (by ishlandmc)
 - Added [Ixeris](https://www.curseforge.com/minecraft/mc-mods/ixeris) (by decce)
 - Added [Reset Controls Confirmation](https://www.curseforge.com/minecraft/mc-mods/reset-controls-confirmation) (by joshieman)
 - Removed [Advanced Loot Info](https://www.curseforge.com/minecraft/mc-mods/advanced-loot-info) (Caused crash on world rejoin)
 - Removed [Bobby](https://www.curseforge.com/minecraft/mc-mods/bobby) (Caused lighting to stop working in rare cases)
 - Removed [Visuality](https://www.curseforge.com/minecraft/mc-mods/visuality) (Replaced)
 - Updated 80 mods


Config Changes
 - Added a new "Villagers" quest category
 - Optimized the c2me config for improved chunk generation speeds and overall performance (Thanks omo50!)
 - Enabled Modernfix Worldgen Allocation for improved world generation speeds
 - Swapped the location of the Quest Book and Teams icons
 - Bound the Open Shulker keybind to N and fixed the Shulker Box quest description being incorrect
 - Improved appearance of mod logo in CrashAssistant screen
 - CrashAssistant will now warn the player when they make too many modifications to the modpack after a game crash
 - Quest categories for the more difficult dimensions now have bold names
 - Fixed GraalVM 21 not always auto-installing when using the server files
 - Fixed some cases of GUI textures missing the Mandalas GUI theming
 - Fixed issue where some inventories would become unsortable
 - Disabled the Accessorify arrow slot, as the Supplementaries Quiver already exists
 - Disabled Subtle Effects waterfalls due to them appearing in places they shouldn’t and causing massive lag
 - Disabled the CrashAssistant MCreator mod detector to prevent user confusion
