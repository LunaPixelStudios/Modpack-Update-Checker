[Major Update]
Mod Changes
 - Added [Hybrid Aquatic](https://www.curseforge.com/minecraft/mc-mods/hybrid-aquatic) (by HybridLabs)
 - Added [Moog's Glow Up](https://www.curseforge.com/minecraft/mc-mods/moogs-glow-up) (by finndog_123)

 - Removed [Fast Noise](https://www.curseforge.com/minecraft/mc-mods/zfastnoise) (Caused world generation to freeze in The End)
 - Updated 65 mods


Config Changes

 - Enabled CrashAssistant simple mode to make the screen much more concise
