### Updates

 - Added 5 combat skill trees, based on the RPG Series Skill Tree and Elemental Wizards: **Weaponry**, **Archery**, **Entropic Magics**, **Coalescent Magics**, and **Agility**. More to come!
 - Added a number of custom performance patches, improving performance by ~20%
 - Power Level on items can now be upgraded in a Smithing Table
 - Added 7 new ships to the end (Moog's End Structures)
 - Added new Relic swords, **Azure Wrath**, **Reach of the Damned**, **Iris** (Witcher)
 - Added new Tier 5 staff, **The Avatar** (Elemental Wizards)
