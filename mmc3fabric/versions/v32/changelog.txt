 - 🔵 Updated 96 mods


### Config Changes
 - Updated magic quest book entries for Spell Engine 1.9
 - Removed Glass Ocean dimension chapter
 - Small changes to the Skill Tree to allow loading on Spell Engine 1.9
 - Disabled Chungus spawning (currently bugged)


### Updates
 - Notice: All spell books will be reset this version, due to changes in Spell Engine
 - Major changes to spell selection across all classes/spell books - some books have been removed or combined, and each book now allows selecting one of multiple spells per each tier
 - All CTOV villages can now spawn in Nature's Spirit biomes
 - Magnet, Pickup, Feeding, Refill, Furance, Blast Furnace upgrades can now be used while the backpack is placed as a block (Traveler's Backpack)
 - Revamped the Forsaken Magus fight (ANARCHY - RPG Factions & Minibosses)
